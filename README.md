# Hearth downloads

**Hearth** is a fast, friendly mod manager for Nexus Mods games on Windows: one-click collections, a built-in Nexus Mods browser, clean hardlink deployment, health checks and load-order sorting.

## Install

1. Open the [latest release](https://github.com/RobbyBobby77/hearth-releases/releases/latest).
2. Download `Hearth_<version>_x64-setup.exe` and run it.

That's it. **Hearth updates itself**: when a new version is out, it downloads it in the background and shows *Restart to update* in the top bar. You can turn this off in Settings → Updates.

Every installer is signed, and Hearth refuses updates that aren't.

## Supported games

Skyrim Special Edition, Skyrim VR, Fallout 4, Fallout 4 VR, Fallout: New Vegas and Cyberpunk 2077, with more on the way.

## Source code

Hearth is free software under the GNU GPL v3. Each release includes `hearth-<version>-source.zip`, the exact source that release was built from.
